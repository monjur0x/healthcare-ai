8-Phase Workflow Summary
Phase
Component
Key Action
1
Multi-Modal Data Ingestion
4 hospitals ingest local CSVs (MIMIC-IV, UCI Heart, Pima Diabetes, CKD) + images (X-ray, MRI, Fundus, Histopathology). Raw data never leaves the hospital.
2
Privacy Preprocessing
Anonymize PII → Apply differential privacy (Opacus) → Secure aggregation setup → Image augmentation + tabular feature engineering.
3
Federated Learning
Each hospital trains local models (tabular: XGBoost/MLP/LSTM; image: EfficientNetV2/DenseNet/Swin-T) → Flower (PyFL) aggregates weights via FedAvg → Global model broadcast back.
4
RAG Knowledge System
Clinical guidelines (PubMed, WHO, CDC, NIH, NICE) → Chunk → Embed (BGE) → Store in Qdrant/ChromaDB → Similarity search → LLM (Llama 3/Qwen 3) generates evidence.
5
Multi-Agent System (CrewAI)
6 specialized agents chain together: Patient Analysis → Disease Prediction → RAG Evidence Retrieval → Treatment Recommendation → Explainability (SHAP/Grad-CAM) → Risk Monitoring.
6
n8n Orchestration
Automated end-to-end pipeline: Receive Data → Trigger Agents → Federated Prediction → RAG Search → Treatment → Explanation → Doctor Alert → Store Results.
7
Clinical Dashboard (Streamlit)
Displays risk scores, mortality/readmission predictions, treatment plans, retrieved evidence, explainable reports, and attention-map visualizations.
8
Evaluation
Compare against 4 baselines (Centralized, Fed-Only, Fed+RAG, Fed+Multi-Agent) using prediction, privacy, RAG, and agent collaboration metrics.
